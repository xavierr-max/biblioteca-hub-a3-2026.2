# Regras de negócio

| Código | Regra |
|---|---|
| RN-01 | Livro exige título, ISBN-13 válido, categoria e pelo menos um autor. |
| RN-02 | ISBN é único. |
| RN-03 | Código de exemplar é único. |
| RN-04 | Exemplar está disponível ou emprestado, nunca ambos. |
| RN-05 | Leitor exige nome e matrícula únicos e válidos. |
| RN-06 | Leitor suspenso não pode emprestar. |
| RN-07 | Máximo de três empréstimos ativos por leitor. |
| RN-08 | Exemplar não pode ser emprestado simultaneamente. |
| RN-09 | Prazo padrão de 14 dias. |
| RN-10 | Empréstimo só pode ser devolvido uma vez. |
| RN-11 | Ativo após vencimento é atrasado. |
| RN-12 | Livro com empréstimo ativo não pode ser arquivado. |
| RN-13 | Histórico de empréstimos não é excluído fisicamente. |
| RN-14 | Criação e devolução ocorrem em transações. |
